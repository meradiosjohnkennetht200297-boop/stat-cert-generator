# 🎓 Statistical Analyst’s Certification Generator

A simple web-based tool for generating **Statistical Analyst’s Certification** documents for undergraduate thesis and research papers.  
The app produces properly formatted certificates in **Word (.docx)** and **PDF (.pdf)**.


## 🛠️ Technologies Used

- HTML, CSS, JavaScript  
- [docx.js](https://www.npmjs.com/package/docx) – Word document generation  
- [FileSaver.js](https://github.com/eligrey/FileSaver.js) – File downloading  
- [jsPDF](https://github.com/parallax/jsPDF) – PDF generation
